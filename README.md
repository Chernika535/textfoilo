# Textfolio

Приложение для создания интерактивных портфолио для тех, кто работает с текстами.

## Первая рабочая версия

Мастерская с десятью форматами работ: статья, лендинг из блоков, цепочка писем, серия постов (Telegram, Instagram, LinkedIn), чат-бот, редактура, SEO-текст, сценарий с видео, сохранённая демонстрация промпта и ветвящаяся история. Есть шесть самостоятельных тем портфолио, настраиваемые разделы верхнего меню, профиль, поиск, фильтры, черновики, дублирование и контекст кейса со сравнительной диаграммой.

Данные автоматически сохраняются в localStorage текущего браузера. Используйте «Резервная копия», чтобы скачать JSON перед очисткой браузера или сменой устройства. «Восстановить из файла» проверяет структуру и запрашивает подтверждение замены. Повреждённые сохранённые данные не перезаписываются автоматически.

«Скачать сайт» создаёт автономный HTML с оформлением и опубликованными работами. Его можно открыть локально или разместить на статическом хостинге. В выгруженном сайте материалы открываются как раскрывающиеся разделы; цепочки, варианты сцен и сохранённые ответы показываются целиком. В приложении есть интерактивные переходы, просмотр писем и постов по одному, переключение редактуры и запуск демонстрации промпта.

Это local-first версия, без регистрации, облачной синхронизации и многопользовательской публикации по персональным ссылкам. У каждого браузера собственные данные. Не добавляйте конфиденциальные материалы в публично размещаемый HTML. Нейросети и реальные почтовые/социальные сервисы не вызываются. Видео загружаются по ссылкам; YouTube и Vimeo встраиваются, MP4/WebM воспроизводятся напрямую.

## Запуск на Windows

Установите Node.js 24 LTS и Git. Склонируйте репозиторий и откройте его папку в терминале:

```powershell
git clone https://github.com/Chernika535/textfoilo.git
cd textfoilo
npm ci
npm run dev
```

Откройте адрес, который напечатает терминал. Не открывайте исходники двойным щелчком как HTML.

```powershell
npm run typecheck
npm test
npm run build
```

## Стек и устройство

TypeScript, React 19, Vinext/Vite, CSS, Lucide. Для этой версии серверная база и платные API не требуются. Структура данных имеет явную версию 1; импорт неизвестных версий отклоняется, не меняя текущее портфолио.

`app/page.tsx` — мастерская; `components/textfolio` — редактор, портфолио, форматы просмотра; `lib/model.ts` — схема и валидация; `lib/storage.ts` — сохранение и скачивание; `lib/export.tsx` — переносимый HTML; `public/portfolio.css` — единое оформление публичного просмотра и экспорта; `tests/model.test.ts` — проверки целостности резервных копий и безопасных ссылок.

Демонстрационные работы вымышлены; числовые результаты помечены как примеры. Следующий этап для полноценного SaaS: аккаунты, серверное хранение, загрузка медиа и публикация отдельных портфолио по адресам.
