# Textfolio

Веб-приложение для портфолио специалистов, которые работают с текстами. Версия 0.2.

## Основной сценарий

После входа открывается пустое портфолио. Добавьте работу, выберите формат, заполните текст и сохраните. Во время редактирования на большом экране рядом показан результат. Создайте разделы меню, заполните профиль и выберите одну из шести тем. Работа может находиться сразу в нескольких разделах.

Десять форматов: статья, лендинг из блоков, почтовая цепочка, серия постов (Telegram / Instagram / LinkedIn), чат-бот с переходами, редактура с реальным сравнением слов, SEO-текст с метаданными и подсветкой запросов, сценарий с готовым видео, промпт с сохранённым ответом, ветвящаяся история. У сцены без вариантов ответа история заканчивается. К текстам можно загружать изображения, к сценарию — видео или ссылку на видеохостинг.

## Хранение и публикация

Аккаунт определяется сервером через Sign in with ChatGPT. Документы сохраняются в Cloudflare D1 с проверкой версии: устаревшее окно не может незаметно затереть новые изменения. Загрузка файлов использует R2. Клиент не передаёт идентификатор владельца как основание для доступа; все операции проверяют серверную сессию. Ссылки на неопубликованные файлы доступны только владельцу. Медиа опубликованных работ доступны вместе с публикацией.

Опубликованное портфолио — отдельный снимок по адресу `/p/your-name`. Черновики туда не попадают. Правки редактора не меняют снимок до следующей публикации. Публикацию можно снять, сохранив документы. Адреса защищены от захвата другим аккаунтом.

Текущий экземпляр Sites остаётся приватным: глобальная настройка доступа ограничивает и `/p/…`. Публичное размещение для анонимных посетителей требует отдельного включения публичного доступа владельцем сервиса. В коде страницы публикаций совместимы с анонимным чтением, а редактор и запись требуют входа.

В браузере остаётся аварийная копия незавершённых сохранений, привязанная к аккаунту. Сервер остаётся основным источником данных. При конфликте сохранение останавливается, и интерфейс предлагает скачать копию перед загрузкой серверной версии. Данные прежней версии из `textfolio:portfolio:v1` не удаляются и не импортируются автоматически. Их можно восстановить JSON-файлом.

JSON-экспорт и восстановление доступны в меню. HTML-экспорт включает опубликованные работы, оформление и загруженные в сервис медиа. Внешние изображения и видео могут требовать интернет. Автономный HTML раскрывает полные материалы и варианты сцен; интерактивные диалоги, почта и истории доступны на опубликованной странице приложения.

## Локальный запуск на Windows

Нужны Node.js 24 и Git.

```powershell
git clone https://github.com/Chernika535/textfoilo.git
cd textfoilo
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_complex_bloodstrike.sql
npm run dev
```

Откройте адрес из терминала. Для локального входа на loopback-адресе используйте `/signin-with-chatgpt?return_to=/`. Локальная база и файлы независимы от опубликованного сервиса. Миграцию на одной локальной базе применяют один раз; последующие миграции применяются по порядку.

## Проверки

```powershell
npm run typecheck
npm test
npm run build
```

Тесты проверяют резервные копии, ссылки, серверную авторизацию, изоляцию аккаунтов, конфликты версий, защиту от запросов с другого сайта, отделение черновиков от публикации, владение адресом, снятие публикации и загрузку/доступ к медиа. Интеграционные тесты исполняют реальные обработчики API поверх SQLite и тестового адаптера D1/R2, а не production-данных.

## Структура

TypeScript, React 19, Vinext/Vite, Drizzle, D1, R2. `app/page.tsx` — редактор портфолио; `app/api` — серверные операции; `app/p/[slug]` — сохранённые публикации; `components/textfolio` — редактирование и представления форматов; `lib/use-portfolio.ts` — синхронизация; `db/schema.ts` и `drizzle` — структура и миграции; `public/portfolio.css` — представление работ и тем.

Платные нейросетевые API не используются. Промпты проигрывают сохранённый автором ответ. Реальные письма и сообщения не отправляются.
